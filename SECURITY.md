## Security Policy
### End-of-life status
This project has reached end of life. Security updates and security support have been discontinued;
vulnerabilities will not be fixed as part of this project.

## Using this software
Use caution if running this software, particularly in production. You are responsible for assessing
and managing the risks of continued use, including evaluating your exposure to known vulnerabilities.
Consider migrating to a maintained alternative. Because this project is no longer maintained,
reports of security vulnerabilities may not receive a response or result in a fix.
